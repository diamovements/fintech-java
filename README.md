# fintech-lesson-1

### Регистрация и вход

Реализованы на основе JWT-токена.
Осуществляются при переходе на эндпоинты ```api/v1/auth/signup``` и ```api/v1/auth/signin```. В теле запроса на оба эндпоинта передаются email и password, для входа еще нужно указать boolean-параметр remember. 
В AuthenticationService пользователю выдается токен после входа в аккаунт, который в зависимости от значения поля "remember" (true/false) остается действительным 30 дней или 10 минут.

_Токен после выдачи необходимо передавать как заголовок Authorization с префиксом Bearer для работы с остальными эндпоинтами._

### Логаут и сброс пароля

Выход реализован с помощью БД для invalidated-токенов. Метод реализован в JwtService путем проверки данного токена на наличие в бд, 
вызывается в AuthenticationService. 

Сброс пароля реализован с java mail, письмо с кодом (он для всех один, хранится в проперти) отправляется на почту пользователя при запросе на эндпоинт:
```api/v1/auth/reset-password/request```, в качестве тела запроса отправляется json с email пользователя.
После этого на указанную почту приходит код с подтверждением, далее необходимо перейти на
```api/v1/auth/reset-password/confirm``` и передать 3 параметра в теле запроса в формате json: email, code, newPassword.

### Роли и права пользователей

В данном задании все пользователи получают роль USER, однако только ADMIN-пользователь может добавлять новые категории и локации.
Все остальные запросы доступны аутентифицированным пользователям, запросы на вход и регистрацию доступны всем.

### Тесты

Написан 1 интеграционный тест для функционала безопасности, в нем проверяются основные эндпоинты, работа с эндпоинтами, в которых необходим заголовок реализована через Wiremock.

### Как все-таки затестить?

Сначала необходимо зарегистрироваться. После регистрации для получения токена надо войти, используя свои данные при регистрации (желательно указать)
рабочую почту, чтобы на нее мог прийти код для сброса пароля). Потом, при желании, можно сменить пароль по инструкции в разделе выше. Да и все, в целом :)
